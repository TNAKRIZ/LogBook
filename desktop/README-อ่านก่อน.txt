LogBook Desktop — บันทึกนักผจญภัย (เวอร์ชันโปรแกรม)
=====================================================

ต่างจากเปิดในเบราว์เซอร์ยังไง
- หน้าต่างลอยโปร่งแสงได้ มองทะลุเห็นเกม มีแถบเลื่อน "ความใส" (เอาเมาส์ไปชี้ที่หน้าต่างลอยจะเห็นปุ่ม)
- คลิกทะลุได้: กดปุ่ม 👆 บนหน้าต่างลอย หรือกด Ctrl+Shift+L (Mac: Cmd+Shift+L) เพื่อเปิด/ปิด
- ลากหน้าต่างลอยไปวางตรงไหนก็ได้ ย่อขยายได้ โปรแกรมจำตำแหน่งไว้ให้
- โปรแกรมไม่ยุ่งกับตัวเกมเลย แค่อ่านภาพหน้าจอที่เราแชร์ให้ (เหมือนในเบราว์เซอร์)

Windows
1. แตกไฟล์ zip ไปไว้ที่ไหนก็ได้ (เช่น Documents)
2. ดับเบิลคลิก "LogBook Desktop.exe"
3. ครั้งแรก Windows จะขึ้นหน้าจอสีฟ้า "Windows protected your PC" เพราะโปรแกรมยังไม่มีลายเซ็นดิจิทัล
   กด "More info" แล้วกด "Run anyway"
4. ถ้าเกมเปิดแบบเต็มจอจริง หน้าต่างลอยจะโดนบัง ให้ตั้งเกมเป็นโหมดหน้าต่าง หรือเต็มจอแบบไม่มีขอบ (borderless)

Mac
1. แตกไฟล์ zip แล้วลาก "LogBook Desktop.app" ไปไว้ในโฟลเดอร์ Applications
2. ครั้งแรกเปิดแล้ว Mac จะบอกว่าตรวจสอบผู้พัฒนาไม่ได้ ให้ไปที่ System Settings > Privacy & Security
   เลื่อนลงมาจะเห็น "LogBook Desktop was blocked" กด "Open Anyway"
3. ตอนกดแชร์หน้าจอครั้งแรก Mac จะขออนุญาต Screen Recording ให้เปิดให้ LogBook Desktop แล้วเปิดโปรแกรมใหม่
- บน Mac หน้าต่างลอยขึ้นทับเกมที่เต็มจอได้ด้วย

ย้ายข้อมูลจากเบราว์เซอร์มาโปรแกรม
ข้อมูลในโปรแกรมแยกจากในเบราว์เซอร์ ถ้าอยากย้าย: ในเบราว์เซอร์ไปที่ ตั้งค่า > ส่งออก (.json)
แล้วในโปรแกรมไปที่ ตั้งค่า > นำเข้า ไฟล์เดียวกัน
