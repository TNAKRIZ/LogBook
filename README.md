# 📖 LogBook · บันทึกนักผจญภัย

> Log your journey, share your glory.

เครื่องมือบันทึกการฟาร์มสำหรับ **MapleStory Classic World** — จดค่าก่อน/หลังฟาร์ม คิดกำไรจริง EXP/ชม. ยาที่ใช้ ของดรอป และทำรูปสรุปแชร์ให้เพื่อน

## เปิดใช้งาน
- **เว็บ:** https://tnakriz.github.io/LogBook/ (ใช้ Chrome หรือ Edge บนคอม)
- **โปรแกรม LogBook Desktop** (หน้าต่างลอยโปร่งแสง คลิกทะลุได้): ดาวน์โหลดที่หน้า [Releases](https://github.com/TNAKRIZ/LogBook/releases) — Windows / Mac

## ทำอะไรได้บ้าง
- ตั้งค่าทีละขั้น: ตัวละคร → แมพ → แชร์จอ → อ่านตัวเลข → ค่าตอนเริ่ม → ยา → หน้าต่างลอย → ตรวจทาน
- อ่านตัวเลข EXP / Meso จากจอเกมเอง พร้อมภาพหลักฐานทุกครั้งที่อ่าน
- หน้าต่างลอยดู EXP/ชม. · %/ชม. · อัปเลเวลอีกกี่นาที · Meso/ชม. โดยไม่ต้องสลับจอ
- สรุปกำไร (Meso จากฟาร์ม − ค่ายา) แยกมูลค่าของดรอป / ETC
- ประวัติ สรุปรายวัน รายแมพ และรูปสรุปสำหรับแชร์

## ความเป็นส่วนตัว
ข้อมูลทั้งหมดเก็บในเครื่องของคุณเอง (ในเบราว์เซอร์ / ในโปรแกรม) ไม่ถูกส่งขึ้นเซิร์ฟเวอร์ ย้ายเครื่องได้ด้วยปุ่ม ส่งออก / นำเข้า ในหน้าตั้งค่า

## เครดิต
ข้อมูลแมพ มอนสเตอร์ และรายการดรอปอ้างอิงจาก [NiaMeowDB](https://meowdb.com) · อัตราดรอปอ้างอิงจาก OSMLib · MapleStory เป็นเครื่องหมายการค้าของ Nexon โปรเจกต์นี้เป็นของแฟนเกม ไม่เกี่ยวข้องกับ Nexon

## สำหรับนักพัฒนา
- `index.html` — ตัวเว็บทั้งหมด (ไฟล์เดียว)
- `desktop/` — โปรแกรม Electron (`npm install && npm start` ในโฟลเดอร์นี้) · สร้างไฟล์ติดตั้งผ่าน GitHub Actions: แท็บ Actions → Build LogBook Desktop
- `tests/` — ชุดทดสอบการอ่านตัวเลข และขั้นตอนตั้งค่า (Playwright)
