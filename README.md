## ทำอะไรได้บ้าง
📈 **EXP / เงิน** — EXP และ Meso ต่อ 10 นาที / ต่อชั่วโมง · อีกกี่ชั่วโมงเลเวลอัพ · นับเฉพาะเวลาที่ฟาร์มจริง (ยืนเฉย ๆ ไม่นับ)
🧭 **ไม่ต้องตั้งค่าเยอะ** — แชร์จอแล้วระบบหาตำแหน่ง EXP / เลเวล / ชื่อแมพ / เงิน ให้เอง · เริ่มรอบ 3 ขั้น
🔔 **อ่านข้อความขวาล่าง** — "You received EXP (+40)" / "gained mesos" / "x1 earned" → นับมอนที่ล้ม EXP แบบเป๊ะ เงินช่วงปิดกระเป๋า ของดรอปใส่ให้ตอนจบรอบ และเด้งเตือนพร้อมเสียงเมื่อได้ของดี (อุปกรณ์ / สกรอล) · ปิดทั้งหมดได้ด้วยช่อง "นับจากข้อความขวาล่าง" หรือปิดแค่เสียงที่ช่อง "🔔 เสียงเตือนของดี"
💬 **แปลแชทในเกม** — อ่านช่องแชท อังกฤษ / เกาหลี แล้วแปลเป็นไทย (แปลในเครื่องด้วย Chrome)
🏁 **จบรอบ** — สรุปพร้อมรูปไว้แชร์ · ใส่ยา / ของดรอปได้ถ้าอยากรู้กำไรสุทธิ (ไม่บังคับ)

## สิ่งที่ต้องมี / ตั้งค่าที่อ่านแม่นที่สุด
- คอมพิวเตอร์ที่ใช้ **Google Chrome** (แปลแชทต้องใช้ Chrome) หรือ Microsoft Edge
- เล่นเกม**แบบหน้าต่าง** หรือ "เต็มจอแบบไม่มีขอบ" (borderless) — ถ้าเต็มจอแบบจริง หน้าต่างลอยจะโดนเกมบัง
- **หน้าต่างเกมกว้าง 1920 ขึ้นไป** · **Windows Scale 100%** · ไม่ยืดภาพ — ตัวเลขในเกมยิ่งใหญ่ ยิ่งอ่านแม่น (หน้าเว็บจะบอกให้ว่าภาพที่แชร์ใหญ่พอไหม)
- ตอนแชร์จอ เลือกแท็บ **"หน้าต่าง"** แล้วเลือกเกม MapleStory

## วิธีใช้งาน

### เริ่มรอบฟาร์ม (3 ขั้น)
1. **จอเกม:** กด "เริ่มแชร์หน้าจอ" แล้วเลือก**หน้าต่างเกม MapleStory** — ระบบหาตำแหน่ง EXP, เลเวล/ชื่อ, ชื่อแมพ และเงินให้เอง
   - เงินในเกมจะเห็นเฉพาะตอนเปิดหน้าต่างกระเป๋า เปิดแป๊บเดียวระบบก็จับได้แล้ว
   - ถ้าช่องไหนอ่านไม่ได้ กด 🎯 แล้วลากกรอบคลุมตัวเลขเองได้ · ไม่อยากแชร์จอก็กรอกตัวเลขเองได้
   - ตัวละครกับแมพ ระบบเลือกให้จากภาพในเกม (จะถามเฉพาะตอนที่ยังไม่รู้)
2. **ค่าตอนเริ่ม:** ตรวจเลเวล, EXP (หรือ %) และเงิน — **เลเวลต้องถูก** เพราะใช้คำนวณ EXP ตอนเกินล้าน
3. **ตรวจทาน** แล้วกด "▶️ เริ่มการผจญภัย"
   - ไม่บังคับ: ใส่ยาที่พกไป (ไว้คิดค่ายา) และตั้งหน้าต่างลอย — กด "แก้ไข" ในหน้าตรวจทาน

### ระหว่างฟาร์ม
- ตัวเลขจะอัปเดตเองทุกไม่กี่วินาที เวลาที่ยืนเฉย ๆ ไม่ได้ฟาร์มจะไม่ถูกนับรวม อัตราต่อชั่วโมงจึงเป็นของเวลาฟาร์มจริง
- ตอนที่ EXP เกิน 1 ล้าน เกมจะไม่โชว์ตัวเลข มีแค่ % ระบบจะคำนวณจาก % กับตาราง EXP ให้ ค่าที่ได้จะมีเครื่องหมาย ≈
- ช่วงที่ปิดกระเป๋า ระบบนับเงินจากข้อความ "gained mesos" ขวาล่าง (ถ้าอ่านไม่ได้จะประมาณจาก EXP) ค่าจะมี ≈ และกลับไปใช้ค่าจริงทันทีที่เปิดกระเป๋า
- ข้อความขวาล่างอย่าให้หน้าต่างอื่นบัง ระบบอ่านทุกวินาทีและนับแต่ละข้อความครั้งเดียว
- อ่านได้ทั้งแมพพื้นมืดและพื้นสว่าง/ลายหิน (ดูจากเงาดำใต้ตัวหนังสือ) แต่ถ้าตัวละครหรือชื่อคนอื่นยืนทับบรรทัดพอดี บรรทัดนั้นอาจอ่านไม่ออก
- ชื่อไอเทมยาวที่เกมตัดเป็น "..." (เช่นสกรอล) ระบบเติมชื่อเต็มจากของที่มอนในแมพนั้นดรอปได้ ถ้าเดาได้ใบเดียว

### จบรอบ
1. กด "⏹️ เลิกเล่น / จบรอบ" — ขึ้นหน้าสรุปทันที (ค่าตอนจบเอามาจากจอ แก้ได้)
2. ไม่บังคับ: ใส่ยาที่เหลือ ของดรอป และ ETC — กด "แก้ไข" ในหน้าสรุป (ของที่อ่านได้จากข้อความขวาล่างใส่ไว้ให้แล้ว แก้จำนวนได้)
3. กด "✅ จบรอบ" แล้วกด "📸 ทำรูปสรุปไว้แชร์" ถ้าอยากเก็บผลไว้

LogBook **ไม่เก็บประวัติ** — แต่ละรอบเริ่มใหม่เสมอ (รีเฟรชหน้าเว็บ = เริ่มใหม่) ถ้าอยากเก็บผล ให้บันทึกรูปสรุปลงเครื่อง

## 🚧 ที่ยังไม่ค่อยเป๊ะ (บอกตรง ๆ)
- **EXP เกิน 1 ล้าน** เกมโชว์แค่ % — ระบบคำนวณจาก % × ตาราง EXP (มีเครื่องหมาย ≈) ต้องใส่**เลเวลให้ถูก**ตอนเริ่ม
- **ตัวเลขเล็กมาก** (หน้าต่างเกมเล็ก) อ่านพลาดได้ — ค่าที่ไม่แน่ใจจะขึ้น "รอยืนยัน" แทนการเดา
- **เงิน** เห็นเฉพาะตอนเปิดกระเป๋า — ระหว่างปิดระบบประมาณจาก EXP (≈) · ตอนเริ่มรอบ**พิมพ์ EXP % กับเงินที่เห็นในเกมเอง**ครั้งแรก ระบบจะเรียนรู้ตัวเลขจากจอคุณได้แม่นขึ้น
- **ข้อความขวาล่าง** ถ้าของดรอปหลายชิ้นเด้งพร้อมกันเร็วมาก หรือข้อความเหมือนกันซ้อนกันทั้งกอง อาจนับขาดบ้าง · ใช้ภาษาอังกฤษในเกม
- **แปลแชท** บรรทัดที่พื้นหลังเป็นฉากสว่างอาจอ่านเพี้ยน · ภาษาจีนแบบพิมพ์อ่านออกเสียง (พินอิน) ยังแปลไม่ได้

## ความเป็นส่วนตัว
- **ไม่เก็บประวัติการเล่น:** ผลแต่ละรอบแสดงบนจอแล้วก็จบ ในเบราว์เซอร์ของคุณเก็บไว้แค่ชื่อตัวละครกับสิ่งที่ระบบเรียนรู้ไว้อ่านตัวเลข (เช่นตำแหน่งกรอบ รูปตัวเลข) ไม่มีการส่งขึ้นเซิร์ฟเวอร์ใด ๆ เพราะ LogBook ไม่มีเซิร์ฟเวอร์
- **ภาพหน้าจอประมวลผลในเครื่อง:** ภาพจอเกมที่แชร์ใช้อ่านตัวเลขในเบราว์เซอร์ของคุณเอง ไม่ถูกอัปโหลดไปไหน หยุดแชร์ได้ทุกเมื่อด้วยปุ่ม "หยุดแชร์" หรือปุ่มของเบราว์เซอร์
- **ไม่มีบัญชี ไม่มีการติดตาม:** ไม่ต้องสมัคร ไม่มีระบบเก็บสถิติผู้ใช้ ไม่มีคุกกี้โฆษณา
- **สิ่งที่โหลดจากภายนอก:** มีแค่ฟอนต์ (Google Fonts) กับตัวอ่านตัวอักษร Tesseract (jsDelivr) ซึ่งเป็นการ*ดาวน์โหลด*มาใช้ในเครื่อง ไม่ได้ส่งข้อมูลของคุณออกไป

## คำถามที่พบบ่อย
**ใช้แล้วไอดีจะโดนแบนไหม?**
✅ อ่านจากหน้าจออย่างเดียว · ไม่แตะไฟล์เกม · ไม่กดปุ่มแทน · ไม่ต้องลงโปรแกรม — เหมือนแชร์จอให้เพื่อนดูหรือสตรีม แต่โปรเจกต์นี้ไม่ได้เกี่ยวข้องกับ Nexon จึงยืนยันแทนผู้ให้บริการเกมไม่ได้ ถ้าวันหนึ่งเกมออกกฎห้าม LogBook จะปิดฟีเจอร์ที่เกี่ยวข้องตาม

**ใช้บนมือถือได้ไหม?**
การแชร์จอเพื่ออ่านตัวเลขต้องใช้ Chrome หรือ Edge บนคอมพิวเตอร์

**อ่านตัวเลขผิดทำยังไง?**
แก้ตัวเลขเองได้ทุกช่อง ถ้าอ่านผิดบ่อย ลองขยายหน้าต่างเกมให้ใหญ่ขึ้น เพราะตัวเลขที่เล็กมากจะอ่านยาก

## เครดิต
ข้อมูลแมพ มอนสเตอร์ รายการดรอป ราคาร้าน NPC และรูปไอเทม อ้างอิงจาก [NiaMeowDB](https://meowdb.com) · อัตราดรอปอ้างอิงจาก OSMLib

MapleStory เป็นเครื่องหมายการค้าของ Nexon โปรเจกต์นี้เป็นผลงานของแฟนเกม ไม่ได้เกี่ยวข้องหรือได้รับการรับรองจาก Nexon

## สำหรับนักพัฒนา
- `index.html` คือตัวเว็บทั้งหมดในไฟล์เดียว เปิดผ่านเว็บเซิร์ฟเวอร์ธรรมดาได้เลย
- `tests/` คือชุดทดสอบการอ่านตัวเลข การหากรอบอัตโนมัติ และขั้นตอนตั้งค่า (Playwright)
- `tools/` คือสคริปต์สร้างข้อมูลแมพ/มอนสเตอร์/ตาราง EXP และฝังรูปไอเทม
